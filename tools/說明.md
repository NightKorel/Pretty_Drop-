# 測試腳本

都是用 Playwright 開本機伺服器實際跑遊戲。先在 repo 根目錄開伺服器：

    python3 -m http.server 8765

再用 `NPMG=$(npm root -g) node tools/檔名.mjs` 執行（Playwright 裝在全域）。截圖會存到 /tmp/pd-shots/（要先建資料夾），不進 repo。

- test.mjs：電腦（高畫質）和手機（低畫質）各開一次，投 20 枚、看有沒有錯誤，截圖。
- bal.mjs：平衡模擬。參數是升級組合，例如 `'[{},{"guard":3}]'`，回報投多少拿回多少。
- layout.mjs：重新產生開局硬幣擺法 start-layout.js（改了檯面或硬幣大小後要重跑）。注意：它會用目前的開局擺法再模擬 4 秒，所以要從「撒幣」重新產生時，要先把 prefill 換回隨機撒幣的版本。
- timing.mjs：模擬慢網路、慢手機，量開啟要多久、每個檔案什麼時候下載完。
- jit.mjs：比較不同物理設定下，原地抖動的硬幣數量。
- shop2.mjs：商店一項一項解鎖、金幣雨。
- set.mjs：沒買大金幣不會出現、設定分頁與音效開關。
- econ.mjs：5 分鐘經濟模擬（含娃娃），比較檯面淨賺和媽媽十元。
- dolls.mjs：把每一套 10 隻史萊姆娃娃排在檯面上拍照。
- book2.mjs：收集 6 種解鎖下一套、圖鑑換套。
- collect.mjs：娃娃推下前緣收集、掉進側溝、圖鑑、存檔。
- vol.mjs：音量滑桿與存檔。
- prog.mjs：升級節奏模擬。參數是分鐘數，自動投幣、買得起最便宜的就買，印出每次購買的時間。
- v20.mjs：一次多投、多套娃娃同時使用。
- v22.mjs：設定「其他」作弊頁、圖鑑放大展示、印出所有升級價錢。
- ach.mjs：成就達成、成就商店（會臨時放一個測試用裝飾品，確認能買、能裝）。
